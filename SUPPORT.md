# Support

Grounded DocParse is a free, open-source, community-driven project maintained
on a best-effort basis. There is no guaranteed response time, service-level
agreement, hosted support service, or promise that every environment or
document type can be diagnosed.

The project does not accept or want donations, sponsorship, or paid support of
any kind. Reproducible bug reports, focused pull requests, and documentation
corrections are the contributions that help — see
[Project participation](#project-participation) below.

## Where to ask

- Use [GitHub Discussions](https://github.com/pypi-ahmad/grounded-docparse/discussions)
  for installation, configuration, usage, and troubleshooting questions.
- Use the [bug report](https://github.com/pypi-ahmad/grounded-docparse/issues/new?template=bug_report.md)
  for reproducible incorrect behavior.
- Use the [feature request](https://github.com/pypi-ahmad/grounded-docparse/issues/new?template=feature_request.md)
  for focused product proposals.
- Use a private [GitHub Security Advisory](https://github.com/pypi-ahmad/grounded-docparse/security/advisories/new)
  for vulnerabilities or sensitive security reports.

Before asking for help, review [setup](SETUP.md), [usage](USAGE.md),
[testing](TESTING.md), and open issues. Provide the release or commit, selected
engine/model, relevant runtime details, and sanitized diagnostics. Do not post
documents, credentials, personal data, result bundles, raw provider responses,
or sensitive local paths.

## Project participation

Helpful contributions include reproducible synthetic fixtures, focused bug
reports, documentation corrections, tests, and narrowly scoped pull requests.
See [CONTRIBUTING.md](CONTRIBUTING.md) and follow the
[code of conduct](CODE_OF_CONDUCT.md).
